# The Split

Matchup desk. Repo: https://github.com/CJD0314/the-split

## Turn this repo into a website (GitHub Pages)

1. Open https://github.com/CJD0314/the-split
2. Click **Settings** (top repo menu).
3. Left sidebar: **Pages**.
4. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Click **Save**.
6. Wait 1–2 minutes. Refresh Pages.
7. Your site is:
   https://cjd0314.github.io/the-split/

## How the repo works

- `index.html` = home page. GitHub Pages always serves this at the root URL.
- Other `.html` files in the same folder = other pages. Links must use those exact names.
- When we change a file here and you refresh Pages, the live site updates.
